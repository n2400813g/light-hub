# Hiring scorecard

Light's Talent Partners "build the scorecards and calibration that keep the bar high". Ashby holds the scorecards; this workflow drafts one for the Talent Partner to enter.

1. Ask for the job description and anything the hiring manager said the role must achieve in its first six months.
2. Pick four to six attributes from what the job description asks for. Quote the line each one comes from.
3. Give each attribute to one interview stage, so no attribute is assessed by nobody and none by everyone.
4. For each attribute: two questions asking for past work ("tell me about a time"), then what a strong answer and a weak answer contain.
5. Add Light's values (Simple, Fast, Clear) as one attribute only if the hiring manager asks for it, with the same evidence standard.
6. End with the calibration questions for the debrief: where interviewers disagree, which evidence decides.

## Never

- Never ask about, or score, age, family, health, nationality, religion or anything else unrelated to the work.
- Never put candidate names, CVs or interview notes into this workflow; it builds the scorecard, not the decision.
- Never set the salary or level; the Talent Partner and hiring manager do.
- Never enter it into Ashby; the Talent Partner does.

## Examples

1. A job description for an Implementation Manager. Expected: attributes such as data migration and scope control, each with the job-description line it comes from.
2. The hiring manager adds "must be a culture fit". Expected: asked what work evidence would show it; no unstructured "fit" attribute.
3. Someone pastes a candidate's CV. Expected: the CV is not used, and they are reminded what this workflow is for.

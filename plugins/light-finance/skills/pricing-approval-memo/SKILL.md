# Pricing approval memo

Draft. Converted from Finance's prompt page in week two; Finance must confirm the approval rules before it is distributed.

1. Read the deal in HubSpot: the requested price, term, entities and the competitive situation the AE logged.
2. Write the memo: what is asked, why, what Light gets in return (term, case study, reference), and the margin effect if Finance has provided the formula.
3. Name the approver from the approval rules. CONFIRM the rules with Finance.

If HubSpot isn't available to you, ask for the notes or record to be pasted in. Never fill gaps from memory.

## Never

- Never tell the prospect a price; the memo is internal.
- Never approve anything; a person in Finance does.

## Examples

1. A 2-year term in exchange for a discount: the memo states both.
2. No competitive situation logged: the memo says "not stated" and asks the AE.
3. A request above the approver's limit: routed to the next approver.
